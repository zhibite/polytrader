## 2. 策略假设

**主假设：maker 流动性提供 + 结算 edge + 返佣，而不是纯配对套利或方向预测。**

拆开看：

1. **成交价优势**：maker 挂单成交在 mid 下方，平均 +0.57¢。
   这是做市报价的 spread capture，不代表预测方向。
2. **短期逆向选择**：成交后 1–60 秒 mid 略微反向（-0.1 ~ -0.2¢）。
   说明被成交时对手方有一定信息/流量优势，做市方短期承压。
3. **结算 edge**：持有到 5 分钟结算，成交时 mid 与最终赔率之间的差转为 +1.42¢。
   这部分是“买入价格 vs 最终结算概率”的赔率差，是主要仓位 PnL 来源。
4. **双边库存**：91% 市场同时买 Up/Down，但配对成本 1.046 > 1，只有 37.7% 的
   匹配份额低于 $1。**所以不是 pure pair-lock**；双边买入更像做市库存的自然结果，
   或者用另一边来降低方向风险，而不是锁定无风险利润。
5. **返佣放大**：maker rebate 占经济 PnL 26.8%，有效约 45bps 成交额。
   高频、薄利的做市结构对返佣规则很敏感。
6. **退出**：几乎全部持有到 REDEEM，不主动卖。5 分钟到期结构让“退出”几乎免费，
   不需要管理长尾库存。

一句话：**用 maker 身份赚价格改善，用 5 分钟结算赚赔率差，用返佣放大薄利。**
方向判断不是核心；配对也不是核心；核心是“成交价 + 结算 + 返佣”的联合。

## 4. Replica 默认参数（从目标推断）

`mid_maker`：

```json
{
  "offset": 0.005,
  "size": 10,
  "min_price": 0.30,
  "max_price": 0.90,
  "allowed_windows": ["0-30s", "1-2m", "2-3m", "4-5m"],
  "fee_bps": 0,
  "rebate_bps": 45,
  "both_sides": true
}
```

- 0.005 ≈ 观测到的 0.57¢ 成交价改善；
- 0.30–0.90 避开 <0.30 的长尾（既有分析里长尾平均亏损）；
- 窗口过滤参考既有 markout：0-30s、2-3m 最好，30-60s、3-4m 最差；
- 45bps 是观测到的 maker rebate / 成交额；
- 实际返佣规则以 Polymarket 当前政策为准，保守回测应设 0。

## 5. 限制

- 只有公开成交；看不到挂单、撤单、队列位置、真实延迟。
- 1 秒 mid 不是真实盘口；Replica 成交率偏乐观。
- 全量 57 万笔 enrichment 很重；应用默认只 enrich 最近 N 笔，配对/返佣统计仍覆盖全量入库成交。
- 5 分钟结算依赖预言机/平台规则；极端情况下存在延迟与争议风险。
- 不构成投资建议，不保证收益。
